# KurilkaTSMU_bot

## Что умеет первая версия
- собирает ФИО и скриншот личного кабинета;
- создаёт индивидуальную ссылку с заявкой на вступление;
- сопоставляет заявку с анкетой;
- отправляет администратору фото, ФИО и Telegram ID;
- позволяет одобрить или отклонить заявку;
- показывает статистику через /stats;
- показывает ожидающие заявки через /pending.

## Что нужно подготовить
1. Токен бота от @BotFather.
2. Telegram ID администратора.
3. ID закрытой группы (обычно начинается с -100).
4. Права бота в группе: приглашение пользователей и управление заявками на вступление.

## Переменные окружения
Создайте переменные:
- BOT_TOKEN (обязательно)
- ADMIN_ID (на первом запуске можно оставить пустым)
- GROUP_ID (на первом запуске можно оставить пустым)
- DB_PATH (необязательно; по умолчанию kurilka.sqlite3)

Не публикуйте BOT_TOKEN и не отправляйте его посторонним.

## Локальный запуск
Требуется Python 3.10 или новее.

    pip install -r requirements.txt
    python bot.py

Для постоянной работы используйте облачный хостинг с поддержкой фонового процесса и постоянным диском/томом. SQLite-файл должен храниться на постоянном диске, иначе данные могут пропасть при пересоздании контейнера.

## Получение ID и первый запуск
1. На первом запуске задайте только BOT_TOKEN, а ADMIN_ID и GROUP_ID оставьте пустыми.
2. Откройте своего бота и отправьте /myid — он покажет ваш Telegram ID.
3. Отправьте /chatid в группе — бот покажет ID группы.
4. Добавьте оба значения в переменные окружения хостинга и перезапустите бота.
5. После этого панель администратора и обработка заявок будут активны.

## Важно
Бот принимает только заявки, пришедшие по выданной им персональной ссылке после заполнения анкеты. Заявки по другим ссылкам отклоняются.
Перед запуском проверьте права администратора и сначала протестируйте процесс со своим вторым аккаунтом.
